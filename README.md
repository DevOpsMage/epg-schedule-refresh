# EPG Schedule Refresh

Stores EPG XML files for IPTV Streams.

## IPTV XML Schedules

This project stores and manages EPG XML files for IPTV streams, allowing you to keep your channel schedules up-to-date. The repo refreshes the XML twice a day to ensure the schedules are current.

### Supported Streams

- [x] Strong8K
- [ ] Trex (Coming Soon)
- [ ] Eagle4K (Coming Soon)
- [ ] Golden OTT (Coming Soon)
- [ ] Lion OTT (Coming Soon)
- [ ] Pro Max (Coming Soon)
- [ ] Python 8K (Coming Soon)

### Usage

Here you will find the url to the EPG XML files from the repo for each supported stream:

- Strong8K: `https://raw.githubusercontent.com/DevOpsMage/epg-schedule-refresh/refs/heads/main/strong8k/strong8k.xml.gz` (gzip-compressed XML)
